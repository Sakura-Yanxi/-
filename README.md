# iPad 截图转 PDF Demo

一个纯前端的小工具，用来把多张 iPad 截图批量合成为一个 PDF 文件。适合截图数量很多、需要快速整理成文档的场景。

## 功能

- 批量选择或拖拽上传图片
- 支持 PNG、JPG 以及浏览器可读取的其他图片格式
- 图片本地预览
- 拖拽排序
- 上移、下移、删除单张截图
- 设置 PDF 页面尺寸
- 设置图片压缩质量
- 设置最大边长，降低大批量截图生成 PDF 时的文件体积
- 自定义导出的 PDF 文件名
- 所有图片处理都在浏览器本地完成，不上传到服务器

## 文件结构

```text
scan/
├── index.html   # 页面入口
├── styles.css   # 页面样式
├── app.js       # 图片读取、排序、压缩、PDF 导出逻辑
└── README.md    # 项目说明
```

## 使用方法

1. 用浏览器打开 `index.html`。
2. 将 iPad 截图拖入上传区域，或点击上传区域选择多张图片。
3. 在预览列表中调整截图顺序。
4. 根据需要设置页面尺寸、图片质量、最大边长和文件名。
5. 点击“生成 PDF”下载结果文件。

## 参数说明

`页面尺寸`

- `跟随截图尺寸`：每一页按对应截图比例生成，适合保留截图原始观感。
- `A4 竖版`：所有截图放入 A4 页面内，适合打印或通用文档。
- `Letter 竖版`：使用 Letter 页面尺寸。

`图片质量`

控制导出 PDF 中图片的 JPEG 压缩质量。质量越高，图片越清晰，文件也越大。截图很多时可以适当降低到 70% 到 85%。

`最大边长`

导出前会把图片按最大边长缩小。截图数量很多时建议使用 `1800 px` 或 `1400 px`，可以明显减少 PDF 体积和浏览器内存压力。

`文件名`

导出的 PDF 文件名。如果没有写 `.pdf` 后缀，程序会自动补上。

## 注意事项

- 这个 demo 使用 jsPDF 生成 PDF，页面会从 CDN 加载依赖：`https://cdn.jsdelivr.net/npm/jspdf@2.5.1/dist/jspdf.umd.min.js`。
- 第一次打开或网络不可用时，可能会出现 PDF 库加载失败，需要联网后刷新页面。
- HEIC 图片是否可用取决于浏览器本身是否支持读取该格式。如果无法读取，可以先在 iPad 或电脑上转换成 PNG/JPG。
- 如果一次放入非常多的超大截图，建议降低图片质量或最大边长，避免浏览器卡顿。

## 本地运行

这是一个静态页面，不需要安装依赖，也不需要启动后端服务。直接双击打开 `index.html` 即可。

如果希望用本地服务打开，也可以在当前目录运行：

```powershell
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```
