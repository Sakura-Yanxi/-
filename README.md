# Sakura Demo Hub

这个仓库用于整理 Sakura 的多个 demo 项目。

## 分支结构

- `main`
  - 仓库首页与索引。
  - 不直接放具体 demo 代码，避免多个项目混在根目录。

- `demo/sakura-question-bank`
  - Sakura 做题集。
  - 本地 PDF 题库、错题复盘、AI 学习教练、每日提醒等功能都在这个分支维护。

- `archive/old-misc-files`
  - 旧脚本和旧笔记归档。

## 推荐使用方式

查看或继续开发 Sakura 做题集：

```powershell
git checkout demo/sakura-question-bank
```
